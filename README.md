# The Comment Above the Code

One funny, painfully honest line imagining the comment a developer left above fragile production code, for the make.fun bounty "The Comment Above the Code". The program `main.ts` writes a single comment to `/output/entry.txt` — a warning taped to a function nobody dares to touch.

The comment: "// Do not touch this function: it is held together by a deprecated library, two TODOs from 2019, and a test suite nobody has dared to run since 2021."
